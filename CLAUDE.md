# Project: Home Assistant Workflowy Integration

## Context
Dit is een custom integratie voor Home Assistant die verbindt met de Workflowy API.
Het doel is om Workflowy bullets te synchroniseren als een `todo` lijst in Home Assistant.

## Ontwikkelregels
- Gebruik altijd asynchrone Python code (`asyncio` en `aiohttp`).
- Zorg dat alle Home Assistant conventies netjes worden gevolgd.
- Schrijf schone code met duidelijke type hints en docstrings.
- Always focus on creating or updating ONE file at a time.
- Always specify the explicit full relative path (e.g., `custom_components/workflowy/todo.py`) in every tool call.
